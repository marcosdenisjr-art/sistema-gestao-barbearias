# Evidências do Discovery

## 1. Objetivo

Este documento registra as evidências coletadas durante o Discovery
realizado com barbearias.

O objetivo é preservar as informações fornecidas pelos participantes
sem misturá-las com interpretações, hipóteses ou decisões de produto.

As interpretações derivadas dessas evidências serão registradas em
documentos posteriores.

---

## 2. Amostra

Foram analisadas 5 respostas ao questionário:

> "Como funciona a gestão da sua barbearia hoje?"

As respostas representam diferentes situações de operação,
tempo de funcionamento e formas de organização.

# 5. Como os horários são controlados

Foram identificadas formas não padronizadas de controle.

Entre as respostas apareceram:

- WhatsApp
- "Outro"

Não foi identificada, nas respostas analisadas, utilização de um
sistema específico de gestão de barbearia para controle dos horários.

# 7. Problemas relacionados aos agendamentos

Foram relatados diferentes problemas:

- Conflito de horários
- Esquecimento de horários
- Cancelamentos
- Demora para responder clientes
- Outros problemas relacionados ao processo de agendamento

# 9. Cadastro de clientes

As respostas mostram diferentes níveis de organização das
informações dos clientes.

Foram identificadas situações em que:

- informações ficam espalhadas pelo WhatsApp;
- não existe cadastro estruturado;
- informações são registradas em outros meios.

Nenhuma das respostas analisadas indicou utilização consistente
de um sistema específico para cadastro de clientes.

---

# 10. Informações consideradas úteis sobre clientes

Entre as informações selecionadas pelos participantes estão:

- Nome
- Telefone
- Data do último atendimento
- Histórico de serviços
- Barbeiro que realizou o atendimento
- Preferências do cliente

- Valores gastos

# 18. Dados relevantes identificados

O Discovery revelou que uma eventual solução poderá lidar com
informações relacionadas a clientes, incluindo:

- Nome;
- Telefone;
- Histórico de serviços;
- Data de atendimento;
- Profissional responsável pelo atendimento;
- Preferências;
- Observações;
- Valores gastos;
- Frequência de visitas.

Esses dados serão analisados posteriormente no contexto de
privacidade e LGPD.

Este documento não determina, neste momento, quais dados deverão
ser efetivamente coletados pelo sistema.

---

# 19. Observação metodológica

As informações deste documento representam as respostas obtidas
no Discovery.

Não devem ser tratadas automaticamente como requisitos do sistema.

O processo seguinte deverá separar:

1. Evidência;
2. Problema identificado;
3. Necessidade;
4. Oportunidade;
5. Hipótese;
6. Requisito;
7. Funcionalidade.

Essa separação será utilizada para manter rastreabilidade entre
o problema observado e as decisões tomadas durante o desenvolvimento.
