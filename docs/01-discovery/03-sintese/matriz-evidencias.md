# Matriz de Evidências

## 1. Objetivo

Esta matriz organiza as evidências obtidas na coleta realizada com
participantes de barbearias.

Seu objetivo é estabelecer rastreabilidade entre:

Coleta bruta → Evidência → Problema identificado → Necessidade → Oportunidade

A matriz registra exclusivamente informações observadas nas respostas.
Interpretações, hipóteses e soluções não fazem parte desta etapa.

## 3. Como interpretar a matriz

Cada evidência recebe uma classificação conforme sua origem na coleta:

- **Contexto** — informação sobre como a barbearia funciona atualmente.
- **Comportamento atual** — forma como uma atividade é realizada hoje.
- **Problema declarado** — situação explicitamente apontada como problema.
- **Frequência** — frequência declarada de ocorrência de determinada situação.
- **Tarefa trabalhosa** — atividade apontada como geradora de esforço.
- **Dificuldade** — dificuldade relatada pelo participante.
- **Necessidade percebida** — informação ou recurso declarado como útil.
- **Melhoria desejada** — mudança explicitamente desejada pelo participante.
- **Necessidade adicional** — necessidade mencionada fora dos principais
  fluxos investigados.

A classificação não representa uma interpretação sobre a causa do problema.
Ela apenas identifica o tipo de informação fornecida pelo participante.

# 13. Observações metodológicas

Esta matriz deve permanecer separada das interpretações do Discovery.

Uma evidência não deve ser transformada automaticamente em:

- requisito;
- funcionalidade;
- regra de negócio;
- solução tecnológica;
- decisão de arquitetura.

Exemplo:

**Evidência:**
"Demora para responder clientes."

**Ainda não significa:**
"Precisamos criar um chatbot."

A hipótese de solução somente deve aparecer em uma etapa posterior,
depois da análise dos problemas e necessidades.
