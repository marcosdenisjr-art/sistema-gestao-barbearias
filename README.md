# Sistema de Gestão para Barbearias

Sistema de gestão desenvolvido para apoiar a operação de barbearias,
com foco em organização de agendamentos, clientes e gestão financeira.

## Status

Em desenvolvimento.

O projeto encontra-se na etapa de organização e documentação
do Discovery realizado com profissionais de barbearias.

## Objetivo

Construir uma solução baseada nas necessidades identificadas
durante o Discovery, mantendo rastreabilidade entre:

- evidências;
- problemas;
- necessidades;
- oportunidades;
- requisitos;
- regras de negócio;
- decisões de produto;
- decisões técnicas.
